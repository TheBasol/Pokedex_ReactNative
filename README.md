

Primero hay que iniciar metro

```sh
# Using npm
npm start

# OR using Yarn
yarn start
```

despues hay que crear los builds

### Android

```sh
# Using npm
npm run android

# OR using Yarn
yarn android
```

### iOS

importante instalar cocoaPods

```sh
bundle install
```

Then, and every time you update your native dependencies, run:

```sh
bundle exec pod install
```


```sh
# Using npm
npm run ios

```
